##  Featured Project — Smart Anti-Theft Item Tracker

An IoT-based tracking system that locates and protects valuable items (bags, laptops, devices) using live GPS, motion/tamper detection, and geofencing.

**Stack:** ESP32 · GPS · GSM/GPRS · Django REST Framework · React · PostgreSQL · Redis · WebSockets · OpenStreetMap

**Highlights:** real-time location dashboard · theft & geofence alerts · battery and device telemetry · location history
